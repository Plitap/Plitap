# PLITAP

**Децентрализованная экосистема цифровых плиток для людей, бизнеса и ИИ.**

Плитка — цифровой объект с владельцем, историей и собственными правилами. Мы развиваем общую спецификацию, пользовательские приложения и возможности для самостоятельных проектов на основе PLITAP.

Сейчас проект находится на этапе проектирования. Публичные материалы будут появляться по мере подготовки.

## Игра на основе PLITAP

Здесь мы вместе придумываем самостоятельную игру и игровые плитки. Окончательной концепции пока нет — мы открыты любым предложениям.

Хотим максимально раскрыть возможности протокола: геопоиск, передачу плиток между участниками, коллекционирование и объединение для усиления. Также рассматриваем бои и завоевание плиток.

Предлагайте свои идеи — от отдельной плитки или игровой механики до целого игрового мира.
